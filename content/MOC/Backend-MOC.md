MOC(Map of Content)는 목차가 아니라 **지도**입니다. 노트가 늘어나면 폴더가 아니라 이 문서에서 링크를 걸어 길을 만듭니다.

## 언어 / 프레임워크

- Java / Spring Boot
- Kotlin
- PHP / CodeIgniter 3

## 데이터

- PostgreSQL / MariaDB
- Redis
- 인덱스와 실행계획
- 트랜잭션과 격리수준

## 아키텍처

- 시스템 설계 (System Design)
- 대용량 트래픽 처리
- 메시징 — Kafka, RabbitMQ
- 캐싱 전략

## 인프라 / 운영

- AWS — EC2, RDS, S3, Lambda
- Docker / Kubernetes
- 모니터링 — ELK, Prometheus

## 엔지니어링 습관

- 클린 코드
- 테스트 전략
- 코드 리뷰 / 멘토링

> [!tip] 사용법
> 아직 노트가 없는 항목은 그냥 텍스트로 두세요. 노트를 만들 때 `[[노트-제목]]` 으로 바꾸면 됩니다.
> Quartz는 아직 만들지 않은 노트로 가는 링크도 깨지지 않게 처리합니다.
