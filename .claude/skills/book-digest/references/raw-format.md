# 원문(raw) 형식 — 절 지도 + 절별 메모

위치 `content/private/<book>-chNN-raw.md`. `private/`는 빌드와 git 둘 다에서 빠지므로 책 문장이 그대로 있어도 된다. 원문은 **정리본을 쓸 때의 유일한 입력**이고, 나중의 내가 "그때 뭘 봤지"를 되짚는 보관소다. 그래서 여기서는 사용자의 말을 고치지 않는다.

## frontmatter

```yaml
---
title: "(원문) Kotlin in Action 1장"
book: kotlin-in-action          # study/<book>/ 폴더명과 같아야 한다
chapter: 1
date: 2026-09-18                # 읽은/적은 날. 정리본 date와 같아도 된다
tags: ["kotlin", "raw"]
status: digested                # raw | digested — 정리본을 만들었으면 digested
digest: study/kotlin-in-action/ch01/index
---
```

`book`·`chapter`·`status`는 verify 스크립트가 읽는다. 빠지면 FAIL.

### 절 지도 표기

| 표기 | 뜻 | 정리본에서 |
|---|---|---|
| `- [x] N.n 제목` | 읽고 메모가 있다 | 주장 절의 재료 |
| `- [ ] N.n 제목 — 이유` | 건너뛰었다 | '넘어간 것'에 들어간다 |
| `- [~] N.n 제목 — 이유` | 훑기만 했다 | '넘어간 것'에 들어간다 |

이유는 사용자의 말로만 적는다. raw나 기존 정리본에 이유가 없으면 `—` 뒤를 비워 두고 보고에서 묻는다. verify는 `[ ]`·`[~]` 항목의 절 번호가 정리본 '넘어간 것'에 전부 있는지 대조한다.

**지도는 `N.n` 한 단계로 유지한다.** `1.3.1`, `1.3.2` 같은 하위 절까지 쪼개면 건너뛴 항목이 열 개 단위로 늘어나고, '넘어간 것'이 그걸 전부 거울처럼 받아야 해서 둘이 어긋난다(실측: 20항 지도를 만든 런에서 하위 절 3개가 '넘어간 것'에서 누락돼 verify FAIL). 하위 절은 부모 절로 올려 한 줄로 적고, 사용자의 메모가 직접 하위 번호를 쓸 때만 그 단계를 쓴다. 지도의 목적은 목차 재현이 아니라 "내가 어디를 안 봤는지"를 한눈에 남기는 것이다.

절 지도가 raw에 없을 때: 책은 사용자만 볼 수 있다. 아는 판본의 목차를 **초안으로 제안하고 확인을 받은 뒤** 채운다. 판본이 다르면 절 번호와 제목이 갈린다(예: Kotlin in Action 1판과 2판은 장 수부터 다르다). 확인 없이 확정하지 않는다.

### 다른 절은 만들지 않는다

원문에 있는 것은 **절 지도 + 절별 메모**(+ 배치를 못 한 메모의 `## 절 미상`)뿐이다. '걸린 것 / 질문'·'다음 장으로 미룬 것' 같은 절은 만들지 않는다. 채울 말이 raw에 없으면 빈 불릿만 남고, 채우려면 사용자가 하지 않은 말을 지어내게 된다.

책 문장에 따로 표기를 붙이지도 않는다. 원문은 `private/`라 공개되지 않고, 정리본으로 새는지는 verify의 전사 비율이 본다.

## 정돈의 한계선

하는 것:

- 메모를 해당 절 아래로 옮기기
- 오탈자 교정 — `표용`→`포용`, `엘비스 연사자`→`엘비스 연산자`, `equlas`→`equals`, `컬렌션`→`컬렉션`. 고친 목록은 보고에 남긴다.
  고치는 것은 **나중에 읽는 내가 잘못 알게 될 오타**, 특히 용어·API 이름이 틀린 것뿐이다. 붙여쓰기(`가질수`), 줄임 어미(`해야함`), 조사 생략은 오타가 아니라 메모 습관이라 그대로 둔다. 여기서 문장을 다듬기 시작하면 정돈이 재작성으로 번진다. 고칠 게 없으면 없다고 보고한다
- 사용자가 `*강조*`나 들여쓰기로 남긴 구조는 그대로 두기
- 절 지도 만들기 (내용은 raw에 있는 것만)

하지 않는 것:

- 문장 다시 쓰기, 두 문장 합치기, 요약하기
- raw에 없는 설명·예시·문장 추가
- 사용자의 축약 표기(`X`, `→`, `ex`) 풀어쓰기
- 어느 절인지 확신이 없는 메모를 추측으로 배치하기

정돈 전후로 단어 집합이 거의 같아야 한다. 많이 달라졌으면 정돈이 아니라 재작성을 한 것이다.
